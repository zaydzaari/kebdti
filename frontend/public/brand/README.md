# Kebdti assets

Original code-native SVG artwork created for this app. `kebdti-mark.svg` is the flat two-voices/one-heart symbol. `kebdti-logo.svg` is the full wordmark. Illustration assets live in `../illustrations` and intentionally contain no UI text. SVGs stay crisp at any display density and require no remote image service.

The design process uses Unslop by Damir Sokolovsky (@heydamir), CC BY 4.0; its source instructions and attribution are retained under `.design/unslop/`.
